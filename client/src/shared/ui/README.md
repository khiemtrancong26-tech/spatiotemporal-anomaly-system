# Component giao diện dùng chung

> Các màn hình dùng cùng nút, trường nhập, trạng thái tải và biểu tượng để giao diện nhất quán.

## Mở file nào

- Chứa Button, Field, LoadingState, ErrorState và nút tải trang tiếp theo. [`primitives.tsx`](primitives.tsx)
- Chứa bộ biểu tượng dùng trong điều hướng và hành động. [`icons.tsx`](icons.tsx)

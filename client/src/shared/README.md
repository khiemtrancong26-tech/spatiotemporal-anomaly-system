# Thành phần dùng chung của frontend

> Các màn hình dùng chung bộ gọi API, nguồn dữ liệu, phân trang và các component cơ bản từ đây.

## Mở file nào

- Gửi HTTP, kiểm tra hợp đồng và xử lý lỗi. [`api/`](api/README.md)
- Cung cấp phương thức gọi dữ liệu theo nghiệp vụ. [`data-source/`](data-source/README.md)
- Quản lý vòng đời phân trang. [`lib/`](lib/README.md)
- Các component hiển thị dùng chung. [`ui/`](ui/README.md)

# Các màn hình theo nghiệp vụ

> Mỗi thư mục con tương ứng với một việc người dùng làm, từ đăng nhập và nhập file đến khám phá, phân tích và review.

## Mở file nào

- Xác thực và phiên người dùng. [`auth/`](auth/README.md)
- Liệt kê và mở dataset đã nhập. [`datasets/`](datasets/README.md)
- Nhập CSV hoặc JSON qua các bước xác nhận. [`dataset-import/`](dataset-import/README.md)
- Khám phá và trực quan dữ liệu trong một dataset. [`workspace/`](workspace/README.md)
- Gửi và theo dõi lần chạy detector. [`analysis/`](analysis/README.md)
- Xem và review điểm bất thường. [`anomalies/`](anomalies/README.md)
- Quản trị người dùng. [`admin-users/`](admin-users/README.md)
- Các thành phần nền và kiểm tra kết nối. [`foundation/`](foundation/README.md)

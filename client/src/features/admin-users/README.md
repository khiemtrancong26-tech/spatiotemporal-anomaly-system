# Màn hình quản trị tài khoản

> Admin dùng màn hình này để xem danh sách tài khoản, tạo người dùng và đổi vai trò hoặc trạng thái hoạt động.

## Mở file nào

- Chứa bảng tài khoản, form tạo/sửa, phân trang và xử lý phản hồi từ API admin. [`page.tsx`](page.tsx)
- Đăng ký đường dẫn của màn hình quản trị. [`../../routes/admin.users.tsx`](../../routes/admin.users.tsx)
- Xem nơi backend kiểm tra quyền và ghi thay đổi. [`../../../../server/src/modules/admin/`](../../../../server/src/modules/admin/README.md)

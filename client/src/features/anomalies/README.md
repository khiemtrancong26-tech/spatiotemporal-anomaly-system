# Danh sách và review bất thường

> Màn hình này giúp analyst xem một phát hiện, tìm số đo gốc rồi ghi chú hoặc đổi trạng thái review.

## Mở file nào

- Tải danh sách và chi tiết theo dataset hoặc run. [`page.tsx`](page.tsx)
- Hiển thị thông tin reading liên quan đến phát hiện. [`reading.tsx`](reading.tsx)
- Soạn thay đổi, gửi phiên bản đang xem và xử lý xung đột. [`review.tsx`](review.tsx)

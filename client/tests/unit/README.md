# Kiểm thử đơn vị frontend

> Nhóm unit test kiểm tra từng hàm, bộ chuyển đổi dữ liệu hoặc quy tắc của frontend.

## Mở file nào

- Hợp đồng API và truy vấn trạng thái phân tích. [`analysis/`](analysis/README.md)
- Cấu hình và xử lý lỗi. [`app/`](app/README.md)
- Phiên đăng nhập. [`auth/`](auth/README.md)
- Tiện ích phân trang. [`shared/`](shared/README.md)
- Bộ lọc, trạng thái và dữ liệu hiển thị. [`workspace/`](workspace/README.md)

Chạy bằng `npm run test:unit --workspace @pm25/client`.

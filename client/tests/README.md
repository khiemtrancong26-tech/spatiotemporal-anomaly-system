# Kiểm thử frontend

> Thư mục này chứa kiểm thử tự động cho frontend. Unit kiểm từng phần nhỏ, integration kiểm luồng kết hợp nhiều thành phần.

## Mở file nào

- Kiểm thử từng phần. [`unit/`](unit/README.md)
- Kiểm thử luồng nhiều thành phần. [`integration/`](integration/README.md)
- Cài matcher DOM và dọn giao diện sau mỗi test. [`setup.ts`](setup.ts)

Chạy từ thư mục gốc bằng `npm test --workspace @pm25/client`.

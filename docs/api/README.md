
# API Contract

## Mục đích

Lưu hợp đồng API giao tiếp giữa Frontend và Backend.

## Trách nhiệm

- Người chủ trì: Khiêm (Backend).
- Thành viên phối hợp: Tài, Duy, Khải.

## Tài liệu dự kiến

- `openapi.yaml`: Đặc tả API của hệ thống.

## Quy tắc

1. Endpoint, request và response phải được thống nhất trước khi tích hợp.
2. Mọi thay đổi API phải được cập nhật trong OpenAPI.
3. Thông báo cho các thành viên bị ảnh hưởng trước khi merge.

## Trạng thái

Chưa triển khai OpenAPI.

Mục tiêu: Công bố hợp đồng API ban đầu vào ngày 3, tuần 1.
